# Security policy

## Supported versions

This is a personal project. Only the latest commit on `main` (release 1.0.0) is maintained, on a best-effort basis.

## Reporting a vulnerability

Please **do not open a public issue**. Report it privately to **contact@lacobble.dev** or through https://support.lacobble.dev, with the steps to reproduce. You will get an answer within a few days.
